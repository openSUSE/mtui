# Seed corpora

One directory per `fuzz_targets/` binary, zipped by `.clusterfuzzlite/build.sh`
into `$OUT/<target>_seed_corpus.zip`, which is the name libFuzzer unpacks before
a run. Without these every target starts from a single generated byte
(`corp: 1/1b` in the run log) and re-derives the input grammar from scratch on
every CI run.

Kept separate from `fuzz/corpus/`, which is cargo-fuzz's generated working
corpus and is gitignored — seeds are inputs we choose, not inputs the fuzzer
found.

Every seed is copied from an existing in-tree test fixture, so no product name,
version or identifier here is invented. To start a local run warm:

```sh
cargo +nightly fuzz run <target> fuzz/seed_corpus/<target>
```

Add a seed when a parser gains a shape the existing files do not cover; keep
them small, since libFuzzer mutates faster on short inputs.
